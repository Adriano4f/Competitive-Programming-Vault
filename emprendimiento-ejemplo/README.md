# Emprendimiento de ejemplo: NaturaJabón

Página web de ejemplo (landing page / tienda) para un emprendimiento ficticio de
jabones artesanales naturales. Es un único archivo HTML autónomo con CSS
embebido, sin dependencias externas ni imágenes externas (usa emojis y SVG
inline como ilustraciones).

## Cómo abrirla

Abre `index.html` directamente en cualquier navegador moderno
(doble clic sobre el archivo, o `Archivo > Abrir` en el navegador).

También puedes servirla localmente:

```sh
cd emprendimiento-ejemplo
python3 -m http.server 8000
# luego visita http://localhost:8000
```

## Secciones

- Encabezado con nombre, eslogan y menú de navegación.
- Hero con mensaje principal y botón "Ver productos".
- Nosotros.
- Productos (cuadrícula de tarjetas con precio y botón "Comprar").
- Contacto (formulario y datos ficticios).
- Pie de página.
